23. CONVERSATION CONTEXT

Do NOT send the entire conversation blindly on every request.

Implement layered context.

Layer 1 — Recent messages

Keep a recent window, approximately:

last 16 messages

Adjust dynamically where necessary.

Layer 2 — Rolling summary

Maintain a conversation summary in D1.

When conversation grows beyond a threshold, update the summary.

Example threshold:

24 uncovered messages
Layer 3 — Relevant history

Retrieve relevant older messages based on the current request.

Start with efficient lexical/relevance retrieval.

Design it so semantic/vector retrieval can be introduced later without rewriting the architecture.

Layer 4 — Persistent memory

Include only relevant user memories.
